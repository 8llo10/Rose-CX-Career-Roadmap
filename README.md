# Rose CX — Career Operating System

Interactive Arabic career operating system for Contact Center and Customer Experience professionals.

## What it does

- Maps progression from Customer Service / Call Center Agent to Team Leader, Supervisor, Manager, Head, Director, VP and Chief Customer Officer.
- Shows realistic **Apply Now / Stretch / Later** roles based on the current career stage.
- Calculates per-role readiness from demonstrable skills.
- Tracks progress locally in each user's browser.
- Includes a 90-day advancement plan for an experienced frontline agent.
- Provides a professional learning path for leadership, QA, WFM, analytics and CX.
- Links to official or established professional sources for certifications and training.
- Includes Saudi-market role evidence explaining why specific skills and experience gates matter.

## Core credential catalog

ASQ CSSGB/CSSBB, Microsoft PL-300, COPC Customer Experience Performance Leader, CCXP, PMP, Genesys certifications, Cisco 300-830 CLCCE, Qualtrics XM, ITIL and Prosci Change Management.

## Design

Arabic RTL responsive interface with a pink glass / mirror visual system.

## Important

Career timelines are directional, not guarantees. Actual hiring requirements vary by employer, industry and scope. Users should verify certification eligibility and current course details with the linked official provider before registering or paying.
